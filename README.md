# React Social App

Учебный проект — мини-соцсеть на React и TypeScript. Делал его, чтобы разобраться с роутингом, авторизацией, работой с сервером и кэшем.

Данные брал с [JSONPlaceholder](https://jsonplaceholder.typicode.com) — это публичное фейковое API.

## Стек

- React 19 + TypeScript
- Vite
- TanStack Query
- React Router
- Mantine

## Что умеет

- Логин и регистрация (без бэкенда: проверяются только поля, данные хранится в localStorage), закрытые роуты через ProtectedRoute
- Список постов с подгрузкой по страницам (useInfiniteQuery)
- Поиск с debounce и сортировкой
- Лайки с оптимистичным обновлением — интерфейс меняется сразу, при ошибке откатывается
- Создание и удаление постов
- Страница поста с комментариями
- Кастомные хуки: useAuth, useDebounce, usePosts, useToggleLike

## Как всё устроено

- Данные с сервера живут в кэше TanStack Query, а своё состояние (авторизация, поиск, модалка) — в useState и контексте
- Все запросы собраны в одном файле postService. Там же я добавляю постам поля likedByMe и likesCount — в JSONPlaceholder их нет
- Страницы получают данные и передают их вниз через пропсы, сами компоненты ничего не запрашивают
- Отфильтрованный и отсортированный список не храню в state, а считаю через useMemo

## Про создание и удаление постов

JSONPlaceholder не сохраняет изменения: на POST и DELETE он отвечает успехом, но данные на сервере не меняются. Из-за этого создание и удаление выглядят необычно: после мутации я инвалидирую кэш, список перезапрашивается — и созданный пост пропадает, а удалённый возвращается.

Я оставил это специально. На настоящем API схема «мутация → инвалидация → рефетч» — стандартный подход, и мне хотелось, чтобы в проекте был именно он. А второй вариант показан на лайках: там кэш обновляется оптимистично, без рефетча, поэтому лайки работают даже с фейковым API. Сам эндпоинт лайков замокан в сервисе — у JSONPlaceholder его нет.

## Ограничения

- Авторизация ненастоящая: подойдёт любой логин и пароль
- Лайки живут только в кэше и сбрасываются при обновлении страницы
- Поиск и сортировка работают по загруженным постам, а не по всей базе

## Запуск

```bash
npm install
npm run dev
```

Ещё есть `npm run build`, `npm run typecheck` и `npm run lint`.

## Структура

```text
src/
  app/         — роуты и layout
  pages/       — страницы
  components/  — компоненты
  hooks/       — кастомные хуки
  services/    — запросы к API
  context/     — авторизация
  types/       — типы
```
